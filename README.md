Udemy Clone Website
A responsive Udemy-inspired website built with HTML and CSS. Features include a navbar with search and user icons, category and topic sections, recommended and popular courses, and a footer. Designed to showcase courses in a clean and organized layout.

HTML5

CSS (Flexbox)

Google Fonts

Font Awesome

Features:

Responsive navigation bar with search functionality

Category and topic sections for course exploration

Recommended and popular courses displayed as cards

Clean and modern UI layout

Fully responsive design for desktop and mobile
